Beacon Scanner is a mobile application developed using React Native. It scans nearby Bluetooth devices, displaying detailed Bluetooth information such as MAC addresses and other relevant data. Users can create events within the app and save beacon data locally to a CSV file. The app requires devices to have Bluetooth Low Energy (BLE) capabilities for accurate scanning. For backend support, Firebase was used for comprehensive user authentication, data storage in Firestore, backend logic via Firebase Cloud Functions, and Firebase Cloud Storage for file storage. This project provides users with a powerful tool for managing and tracking Bluetooth beacon data seamlessly.
